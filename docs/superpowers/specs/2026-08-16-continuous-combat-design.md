# 持续自动战斗设计

## 目标

将已通过实机验证的“同平台试运行 15 秒”改为持续自动运行。用户点击“开始自动运行”后，复用现有视觉观察、动作策略和 `Maple.InputBroker.exe` 输入闭环，不再由固定计时器终止。

## 交互

- 空闲或暂停时显示“开始自动运行”。
- 运行时显示“暂停并释放按键”，重复点击不会创建第二个运行任务。
- `F9` 暂停或恢复，`F12` 紧急停止。
- 启动倒计时和自动切回游戏窗口保持不变。

## 停止与安全

以下任一条件立即停止动作并调用 `ReleaseAllAsync`：用户暂停、`F9`、`F12`、游戏失焦、目标窗口身份变化、输入服务异常、视觉安全门失败、程序退出。持续运行不绕过现有安全门，也不直接从 React 发送按键。

## 实现边界

- 移除试运行控制器的 15 秒取消计时，仅保留显式取消令牌。
- 将 UI 命令和文案从限时试运行调整为持续运行；保留现有抽象动作协议。
- 用单元测试覆盖“超过 15 秒不自动取消”“暂停会释放按键”“运行中不能重复启动”，再做一次有界实机启动/暂停验收。
